# Spec M28 — `mc lsp`: the taught compiler as language server (design panel first)

Principle: only the project's taught compiler knows the developer's syntax, so the server IS that
compiler in `lsp` mode. Nothing about any specific taught language enters the server; it exposes what
the parser knows: tokens with classes (core keyword, taught word, operator incl. taught operators,
identifier, literal, directive, hole), declarations and uses (functions, globals, locals, params,
defines, rules, syntax words, aliases), diagnostics with positions (including `instantiated from`).

## Protocol
- JSON-RPC 2.0 over stdio (`Content-Length` framing), JSON reader/writer in `.mc` (`src/json.mc`),
  UTF-16 column mapping for positions. Capabilities: `textDocument/didOpen|didChange|didClose` (full
  sync), `publishDiagnostics`, `semanticTokens/full`, `definition`, `references`, `hover`,
  `documentSymbol`, `completion` (names in scope + taught words), `shutdown/exit`.
- One parse per change of the whole unit (fast: the compiler parses itself in ~50 ms); tables are
  reset between parses (the compiler already runs `user_init` + parse per process; `lsp` mode loops).
- Position provenance: the lexer records `(file, line, col, len)` per token (col is new; today only
  line) and nodes keep the token index of their name; a side table maps declarations to uses.
- Project awareness: the extension reads `mc.toml`; if `[compiler].modules` exists it builds the
  taught compiler (`mc build --compiler-only`) and launches *that* binary with `lsp`, so hooks are live.

## Design panel (before implementation, like M21)
Three angles: (a) minimal protocol surface; (b) provenance model (how uses are tracked without a type
checker; taught constructs mapping to ranges); (c) performance/incrementality. Judges score, synthesis
rewrites this spec.

## Acceptance
Scripted client tests (`editor/lsp-tests/`, in `make check` when node is present or via a `.mc` client):
open `examples/lang/main.lx` through the taught compiler; semantic tokens mark `class`, `ref`,
`namespace` as taught words and `.`-access as taught operator; definition of a method resolves to the
`class` body line; references of a field list every `.field` use; a syntax error reports the right
range; hover on a `#define` shows its value.
