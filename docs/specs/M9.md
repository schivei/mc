# Spec M9 — `#rule` (peça C da superfície) + `lib/prelude.mc`

Pré-requisito: M7 fechado (ponto fixo, golden gravado). Este marco muda o stage0 **e** o `src/`
(o mecanismo custa duas vezes), e termina com o ponto fixo reverificado.

## Sintaxe (definitiva; ver `docs/plan.md` § Superfície)
```
#rule stmt: while ( expr $c ) block $b  =>  loop { if (!$c) break; $b }
#rule stmt: for ( stmt $init expr $cond ; expr $step ) block $b
    => { $init loop { if (!$cond) break; $b $step; } }
#rule stmt: ident $x += expr $e ;  =>  $x = $x + $e;
#rule stmt: ident $x ++ ;          =>  $x = $x + 1;
```
- `#rule stmt:` é a única categoria no M9 (`expr:` fica reservada; erro claro se usada).
- Padrão: sequência plana de itens; item = token literal (qualquer lexema, inclusive os criados
  por `#token` — `+=` e `++` precisam de `#token` antes) ou `nt $nome` com
  `nt ∈ {expr, stmt, block, ident, type}`. O **primeiro item é sempre um token literal**; se for um
  identificador (`while`), ele passa a ser palavra-chave reservada (registrado via `tok_add` como
  word) — a partir daí não pode ser usado como nome.
- Template: um statement (ou bloco) parseado **na definição** com o parser normal, onde `$nome`
  vira `N_HOLE` (índice do binding) e `$$nome` vira `N_HOLE` de gensym.
- Sem alternação/opcional/repetição no padrão.

## Semântica
- Indexação por token de abertura: tabela linear `{tok, nitems, items[], tmpl}`; ao iniciar um
  statement, se o token corrente abre alguma regra, tenta-se a regra (a última definida para o
  mesmo token vence). Casamento é determinístico e sem backtracking: cada item literal deve casar,
  cada `nt $x` chama o sub-parser correspondente (`parse_expr`, `parse_stmt`, `parse_block`,
  ident, type). Falha = erro de sintaxe apontando o item.
- Expansão: `node_copy_subst` com os bindings; `$$nome` gera um local fresco por expansão
  (`__g<N>`, contador global determinístico) — o template pode declará-lo (`i64 $$t = ...;`).
- Reexpansão: o resultado passa de novo pelo parser de statements? Não — o template já foi
  parseado; regras dentro do template já foram expandidas na definição. Regras que usam regras
  funcionam naturalmente. Recursão infinita é impossível por construção (não há reexpansão
  textual). Limite de 64 níveis de aninhamento de regra na definição.
- **Frame calculado depois da expansão**: já é o caso (o gen percorre a AST expandida).
- `ident $x` casa só `T_IDENT` e produz `N_IDENT`. `type $t` produz um nó `N_TYPE` (novo, kind
  reservado) usado só como buraco em declarações `type $t ident $x = expr $e;` — **fora do escopo
  do M9** se custar mais de 20 linhas; documentar.
- `--dump-ast` mostra a AST **expandida**; adicionar `--dump-rules` (lista regras: token de
  abertura, itens, tamanho do template) para diagnóstico.

## `lib/prelude.mc`
`#token "+="`, `"-="`, `"++"`, `"--"`; regras `while`, `for`, `+=`, `-=`, `++`, `--`, `until`?
(não), `unless` (não). Só o que o `mc.mc` vai usar. **Nada de `struct` no M9** — fica para um M9.5
depois de medir o custo; o plano previa, mas o M6 mostrou que o `#define`+acessora funciona e
`struct` real exige `type $t` e layout, que é mais que `#rule` entrega.
