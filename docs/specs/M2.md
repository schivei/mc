# Spec M2 — locais, parâmetros, if/else, loop/break N/continue, chamadas, extern, arrays locais, memória

Pré-requisito: M1 fechado e revisado. Leia `docs/plan.md`, `docs/specs/M1.md` e o código atual.
Escopo: tudo que uma função precisa para computar e chamar outras funções. Fora (M3): globais,
strings literais, `#include`, `#define`, arena, `__cstring`/`__data`/`__bss`.

## Parser
- Statements novos: `tipo nome = expr;`, `tipo nome;`, `tipo nome[CONST];` (N_VAR: name, type,
  a=init ou 0, val=nº de elementos ou 0), `nome = expr;` (N_ASSIGN: name, a=expr),
  `if (expr) stmt [else stmt]` (N_IF a,b,c), `loop stmt` (N_LOOP a), `break;`/`break N;`
  (N_BREAK val=N, default 1), `continue;` (N_CONTINUE), `return [expr];`, bloco, `expr;`.
- Top-level novo: `extern tipo nome(params);` (N_EXTERN) e funções com parâmetros
  `tipo nome(tipo a, tipo b, ...)` — máx. 8 params, erro se exceder.
- Expressões novas: `&nome` (N_ADDR, prefixo `&` prec de unário), chamada `nome(args)` já parseada
  no M1 (N_CALL: name, a=lista de args).
- Escopo: blocos aninhados podem sombrear; resolução do mais interno para fora. Implementar com
  uma pilha plana de locais `{name, type, offset, nelem}` + marca de tamanho por bloco.

## Codegen
- **Frame**: cada local/param ocupa um slot de 8 bytes (arrays: `nelem * largura` arredondado a 16);
  offsets negativos a partir de x29, atribuídos na ordem de declaração; sem reuso de slot.
  `frame = round16(slots + spills)`. `sub sp` ≤ 4095 senão erro. Calcular o frame ANTES de
  encodar mas DEPOIS de percorrer a função inteira (contar locais de blocos aninhados).
- **Params**: prólogo grava `x0..x7` nos slots (`str xN, [x29, #-off]`), sem tocar em `x0..x7`.
- **Registradores por profundidade** (do plano): depth 0..6 → `x9..x15`. **Spill**: depth ≥ 7 vai
  para slot de spill no frame; operações com operando spillado carregam em `x16`/`x17`. Rastrear a
  profundidade máxima da função para dimensionar a área de spill.
- **Chamada**: avaliar args nas profundidades `cur..cur+n-1`; gravar `x9..x(9+cur-1)` (os vivos)
  nos slots de salvamento dedicados por profundidade; `mov x0..x(n-1)` dos args; `bl _nome`
  (reloc `R_BRANCH26`, pcrel=1, len=2 via `reloc_add`; `sym_ref` para externos, símbolo definido
  para funções do arquivo); `mov x(9+cur), x0`; restaurar os vivos. Funções chamadas antes de
  definidas: registrar TODAS as assinaturas (N_FUNC/N_EXTERN) antes de gerar corpos.
  Checagens: aridade; chamada a nome desconhecido = erro.
- **Intrinsics** (reconhecidas por nome em N_CALL, não são símbolos): `ld8/ld16/ld32/ld64(p)` →
  `ldrb w/ldrh w/ldr w/ldr x` (zero-extend); `st8/st16/st32/st64(p, v)` → `strb/strh/str w/str x`.
  Tipos de retorno: u8/u16/u32/u64; st* é void.
- **Locais**: leitura `ldr` com largura do tipo (zero-extend); escrita `str` com largura; array
  como valor = `sub xd, x29, #off` (endereço, tipo uptr). `&nome` = mesmo endereço.
- **Controle**: `if` com `cbz`; `loop` com labels início/fim; pilha de loops para `break N`
  (N > profundidade = erro) e `continue`; `return` → `x0` + `b` para o epílogo.
- Atribuição a array ou a nome desconhecido = erro. Tipo de `nome` em expressão = tipo declarado.
- Manter `--dump-asm` cobrindo tudo (str/ldr com offsets, bl com símbolo, labels).

## Testes (todos com `// expect-exit` e/ou `// expect-stdout`)
- `010-locals.mc`: locais, atribuição, sombreamento em bloco → 42.
- `011-loop.mc`: soma 1..n com `loop`/`break`/`continue` → 55 (n=10).
- `012-call.mc`: `fib(10)` recursivo → 55; função com 8 params somando → exit conhecido.
- `013-putnum.mc`: `extern i64 write(i64 fd, uptr buf, i64 n);` + `putnum` (array local u8[24],
  `st8`, `/`, `%`) imprimindo `fib(24)` → stdout `46368\n` (o `\n` gravado com `st8(buf+i, 10)`),
  exit 0.
- `014-ldst.mc`: `u8 b[16]`; `st32(b, 0x11223344); st16(b+8, 0xBEEF);` e `return ld8(b+1) +
  ld16(b+8) ...` com resultado dobrado para 42; teste de zero-extend (`ld8` de 0xff = 255).
- `015-break-n.mc`: dois loops aninhados com `break 2` → 42.
- `016-spill.mc`: expressão com profundidade ≥ 9 (ex.: chamada com 8 args cujos args são chamadas)
  → resultado conhecido.
