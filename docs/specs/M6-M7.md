# Spec M6 — `src/mc.mc`: o compilador auto-hospedado · Spec M7 — ponto fixo

Pré-requisito: M5 fechado (o stage0 é a especificação executável; congelar seu comportamento antes
de começar). Este é o marco que domina o cronograma. Regras de ouro:
1. **Transliteração, não reescrita.** Um arquivo `.mc` por arquivo `.c`, mesmas funções, mesmos
   nomes, mesma ordem, mesma forma de I/O. Divergir de propósito é proibido — a única liberdade é a
   imposta pela linguagem (sem structs, sem ponteiros tipados).
2. **Só o núcleo.** Nada de `#rule`, `while`, `struct`, prelúdio. `loop { if (!c) break; ... }` à mão.
3. **Acessoras sempre.** Cada "struct" do C vira um layout `#define CAMPO_X off` + `x_campo(p)` /
   `set_x_campo(p, v)`. Zero `ld64(p + 16)` fora das acessoras.

## Layouts (dados planos em arena; todos os campos de 8 bytes salvo indicação)
| C | .mc | campos |
|---|---|---|
| `Token` | `TOK_*` | id, start(uptr), len, val, line — 40 B |
| `TokEnt` | `TE_*` | text(uptr), len, word, id — 32 B |
| `Node` | `ND_*` | kind, op, type, val, name(uptr), a, b, c, d, next, line — 88 B |
| `InfixEnt`/`PrefixEnt` | `IN_*`/`PR_*` | tok, prec, right, tmpl / tok, tmpl |
| `Ins` | `INS_*` | op, rd, rn, rm, imm, label, sym — 56 B |
| `Section` | `SEC_*` | seg(16 B inline), sect(16 B inline), flags, align, data(Buf inline: p,len,cap), zsize, rel(uptr), nrel, relcap |
| `Symbol` | `SYM_*` | name(uptr), sect, value, global — 32 B |
| `Reloc` | `REL_*` | off, sym, type, pcrel, len — 40 B |
| `Buf` | `BUF_*` | p(uptr), len, cap — 24 B |
Arrays de registros = base + índice * tamanho. Strings C = `uptr` para bytes NUL-terminados na arena.

## Arquivos
`src/arena.mc` (xalloc, buf_*, out_*, die, read_file, write_file, cstrlen, str_eq, mem_eq),
`src/lex.mc` (já existe do M4; ajustar ao layout), `src/ast.mc`, `src/parse.mc`, `src/gen_arm64.mc`,
`src/macho.mc`, `src/main.mc` (driver, mesma CLI: `mc [--dump-*] in.mc [-o out.o]`).
`src/mc.mc` = `#include` de todos na ordem de dependência. A arena é `u8 heap[HEAP_SIZE]` em bss.

## Estratégia de entrega (fatias verificáveis, nesta ordem)
1. `arena.mc` + teste: escreve um arquivo e relê → igual.
2. `macho.mc` + `src/m0.mc`: reproduz o M0 (o `.o` de `movz x0,#42; ret`) e o `.o` deve ser
   **byte a byte igual** ao que `build/mc0` gera para `tests/001-return42.mc`. Isto é o primeiro
   teste cruzado de verdade e fecha o writer antes de qualquer front-end.
3. `ast.mc` + `parse.mc` (com `lex.mc`): `--dump-ast` de todos os `tests/*.mc` idêntico ao do `mc0`
   (`scripts/check-ast.sh`, molde do `check-lex.sh`).
4. `gen_arm64.mc`: `--dump-asm` idêntico ao do `mc0` para todos os testes (`scripts/check-asm.sh`).
5. `main.mc`: `.o` idêntico (`cmp`) ao do `mc0` para todos os testes (`scripts/check-obj.sh`).
6. `make test` com `build/mc1` (= `mc0 src/mc.mc`, linkado) passando a mesma suíte.

## M7 — ponto fixo
`scripts/bootstrap.sh`:
```
build/mc0 src/mc.mc -o build/mc1.o && scripts/link.sh build/mc1 build/mc1.o
build/mc1 src/mc.mc -o build/mc2.o && scripts/link.sh build/mc2 build/mc2.o
build/mc2 src/mc.mc -o build/mc3.o
cmp build/mc2.o build/mc3.o            # o critério
shasum -a 256 build/mc2.o | diff - tests/golden/mc2.sha256   # (criar na primeira vez)
```
`make bootstrap` chama o script. `mc1.o` vs `mc2.o` **podem** diferir (compiladores diferentes);
`mc2.o == mc3.o` é o que prova. Divergência → `diff <(build/mc1 --dump-asm src/mc.mc)
<(build/mc2 --dump-asm src/mc.mc)` e bissectar por função.

## Aceite
`make bootstrap` verde; `scripts/test.sh build/mc2` verde; golden gravado. Tamanho de `src/*.mc`
reportado. Tempo de `mc1 src/mc.mc` reportado (esperado: bem abaixo de 1 s).
