# Spec M21 — Tier 3 completion: expression, infix and type hooks; token record/replay

Goal: enough parser surface for a `.mc` module to define a higher-level language on top of the core
(see M22). Everything in `src/*.mc`; stage0 untouched.

## New hooks (`src/hooks.mc`, `src/parse.mc`)
- `syntax_expr(word, fn)`: `parse_primary` calls `fn()` when the current token is the registered word;
  the handler consumes tokens and returns a node index (expression). Used for `new`, `ref`, `sizeof`-like
  forms, `null`.
- `syntax_infix(word, prec, fn)`: registers `word` as an infix/postfix operator handled by code: in the
  Pratt loop, when the operator matches, the parser calls `fn(left)` and the handler parses whatever
  follows (a name, `(args)`, `[index]`, `<types>`) and returns the resulting node. Used for `.` member
  access and method calls. Precedence table shared with `#infix`.
- `syntax_type(word, fn)`: `p_type()` (and every core path that reads a type: globals, locals, params,
  casts, `extern`) calls `fn()` when the current identifier is registered; the handler consumes the type
  syntax (e.g. `List<i64>`) and returns a `TY_*` (objects are `TY_UPTR`). Enables generic instantiation
  at the point of use.
- `on_func_end(fn)`: called after each top-level function body is parsed with the `N_FUNC` index, so a
  module can post-process bodies (insert calls at scope exits, rewrite identifiers). Optional helper for
  modules that do not define their own function syntax.

## Token record/replay (`src/lex.mc`, `src/parse.mc`)
- `p_record_begin()` / `p_record_end() -> uptr tokens, i64 count`: every token consumed between the two
  calls is copied (id, start, len, val, line, file) into an arena array; nesting depth of `{}` is the
  caller's business. The parser keeps parsing normally while recording (used to skip a generic body:
  record while calling `parse_block` on a throwaway, or record raw with `p_skip_balanced()`).
- `p_skip_balanced(open, close) -> tokens, count`: consumes and records a balanced token span without
  parsing it (generic class bodies are stored unparsed).
- `p_replay(tokens, count, subst_from, subst_to, nsubst)`: pushes a token source onto the lexer stack;
  `lex_next` serves those tokens first (with identifier substitution: token text equal to
  `subst_from[i]` is replaced by the tokens of `subst_to[i]`, which may be a type name or a literal),
  then returns to the underlying source. File/line of replayed tokens are kept for diagnostics, and the
  parser reports `instantiated from <file:line>` when an error happens inside a replay (one level).
- Limits: `MAXREPLAY 16` nested replays, recorded spans up to 64 K tokens.

## Small core conveniences
- `p_peek_id()` (next token id without consuming), `p_mark()/p_reset()` (rewind within the current
  file for one-token lookahead beyond `peek`), `type_width_of(ty)`.
- `#define` scoping is still global; modules that need per-instantiation constants use replay
  substitution, not `#define`.

## Acceptance

  twice with different literals); `scripts/check-surface.sh` covers them.
