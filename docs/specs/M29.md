# Spec M29 — VS Code extension (`editor/vscode`)

- TypeScript, `vscode-languageclient`; language ids `mc` (`.mc`) and a configurable list of taught
  extensions (`.lx`, from `mc.toml` `[editor] extensions = [...]`).
- TextMate baseline grammar for `.mc` (used before the server answers); semantic tokens from `mc lsp`
  override colors; theme contributions for `taughtWord`, `taughtOperator`, `hole`, `directive`.
- Commands: `mc: Build` (runs `mc build`, problem matcher parses `file:line: message`), `mc: Run`,
  `mc: Show dump (tokens/ast/asm/rules/machine)` in a virtual document, `mc: Rebuild taught compiler`.
- Debug: contributes a `lldb-dap` launch configuration provider (M30) pointing at the `--exe` output.
- Packaging: `vsce package` -> `.vsix`; CI job builds it; README with screenshots.
- Tests: Extension Host smoke test (activation, server start, one semantic token request).
