# Spec M5.5 — correções das revisões M3/M5 + núcleo que o M6 precisa

## A. Correções (revisão M3)
1. **Lexer**: escape `\0` dentro de string literal é erro (`"\0 nao permitido em string"`); em char
   literal continua válido. Motivo: `S_CSTRING_LITERALS` faz o `ld` fundir literais por C-string,
   corrompendo `"a\0b"` vs `"a"`. Documentar em `docs/core-language.md` (uma linha).
2. **`#include`**: `path_join` normaliza `.` e `..` lexicamente (sem filesystem) antes do once-only.
   Teste: `a/b.mc` incluindo `../c.mc` + raiz incluindo `c.mc` → uma inclusão só.
3. **Token carrega arquivo**: `Token.file`; `node_new`/`err_at` usam o arquivo do token que deu a
   linha, não o arquivo corrente do lexer. Teste: `frag.mc` com `i64 helper(i64 x) {` sem fechar →
   erro cita `frag.mc`.
4. **`#define` vs nome**: declarar local, parâmetro, global ou função com nome de `#define` existente
   é erro `nome ja definido por #define`.
5. Reduções seguras em `gen_arm64.c` (dump via tabelas `rrr`, tabela ld/st, `mem_op` unificado,
   helper de resolução de nome) — meta ≈ −25 linhas, sem mudar o código gerado (conferir com
   `cmp` dos `.o` de todos os testes antes/depois).

## B. Correções (M5)
6. Ordem das seções nos load commands: `__text`, `__cstring`, `__data`, `__bss` (as que existirem)
   e só depois as custom, na ordem de primeira aparição. `#section` registra numa tabela; criação
   real em `gen_sections`. Reconferir `otool -l` de 030.

## C. Núcleo novo (pedido do M4)
7. **Inicializador de array global**: `tipo nome[N] = { e1, e2, ... };` e `tipo nome[] = { ... }`
   (N inferido). Elementos: constantes dobradas (escritas com a largura do tipo) ou, para `uptr`,
   string literal → 8 bytes zero + `R_UNSIGNED` (len 3, pcrel 0, extern 1) para `l_strN`.
   Vai para `__data` (ou seção custom não-zerofill), alinhado a 16; N > count preenche com zeros;
   count > N é erro. Suporta `#opcode`? Não. Teste: `uptr names[] = {"zero","um","dois"};` com
   `puts(ld64(names + 8*i))` → stdout `um`; `u32 t[4] = {1,2,3};` → `ld32(t+8) == 3`.
8. **Divisão sem sinal**: `/` e `%` com operando esquerdo `u8/u16/u32/u64/uptr` → `udiv`/`msub`;
   `fold` espelha. Teste: `(u64) 0xFFFFFFFFFFFFFFFF / 2` = `0x7FFFFFFFFFFFFFFF`.
9. **Protótipo**: `tipo nome(params);` no top-level registra assinatura; definição posterior deve
   bater (tipo de retorno e aridade); protótipo sem definição nem extern = erro no fim.
10. `Makefile`: alvo `check-lex` (`scripts/check-lex.sh build/mc0`); `make test` continua igual.
11. `CLAUDE.md` § Estado: M3, M4, M5 e M5.5 fechados; próximo M6.
