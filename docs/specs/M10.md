# Spec M10 — Tier 2: passes e backends ensinados pela superfície

Pré-requisito: M9 fechado (golden atualizado). Prova o requisito central: um backend escrito em
`.mc`, fora do compilador, produz `__text` byte a byte igual ao embutido.

## Núcleo (pequeno, nos dois lados)
1. **Endereço de função**: `&nome` onde `nome` é função/extern → `uptr` (adrp/add com reloc
   `PAGE21`/`PAGEOFF12` para `_nome`).
2. **Chamada indireta**: intrínseco `callp(p, a1, ..., a7)` → args em `x0..x6`, `blr` via `x8`?
   Não: carregar `p` em `x16` (IP0, caller-saved, fora de `x0..x7`) e `blr x16`. Salvamento das
   profundidades vivas igual ao `bl`. Tipo de retorno `i64`.
3. **Hook de usuário**: `src/mc.mc` inclui `src/user.mc`, que por padrão inclui
   `lib/user_default.mc` contendo `void user_init() { }`. O driver chama `user_init()` antes de
   parsear. **Ensinar o compilador = editar `src/user.mc` para incluir seus módulos e rodar
   `make mc1`** (o `mc` recompila a si mesmo com o módulo dentro). Sem dylib, sem ABI.
4. **Registro** (`src/hooks.mc`, parte do compilador): `pass(uptr fn)` adiciona a uma tabela
   linear; `backend(uptr name, uptr fn)` idem. Driver: após `parse_unit` e `fold`, aplica cada pass
   em ordem (`root = callp(fn, root)`); escolhe backend por `--backend=NOME` (default `macho`,
   embutido) e chama `callp(fn, root, out_path)`.
5. **Divisão do gen**: `gen_unit(root)` passa a ter duas metades com nomes públicos:
   `gen_lower(root)` (AST → buffers `Ins` por função + tabelas de globais/strings, sem encodar) e
   `gen_encode_all()` + `macho_write(out)`. O backend embutido `macho` = `gen_lower` +
   `gen_encode_all` + `macho_write`. O buffer `Ins` de cada função e as tabelas ficam acessíveis
   por acessoras (`ins_count(f)`, `ins_at(f, i)`, `func_count()`, `func_name(f)` …).

## Prova (na superfície, em `lib/`)
- `lib/backend_arm64.mc`: backend `arm64-surface` que chama `gen_lower`, e então **reimplementa o
  encoder** em `.mc` usando só a API pública: tabelas de opcodes (as mesmas fórmulas de `encode`,
  escritas de novo — pode copiar), labels/fixups, `sec_new/sym_new/reloc_add/buf_u32` de
  `macho.mc`, `macho_write`. Registrado em `user_init` de `lib/user_backend_demo.mc`.
- `lib/pass_demo.mc`: pass que percorre a AST e troca `x * 1` por `x` (ou conta nós e imprime em
  stderr) — prova que a AST é operável de fora.
- Aceite: com `src/user.mc` incluindo os dois módulos, `make mc1`; para cada `tests/*.mc`,
  `build/mc1 --backend=arm64-surface X -o a.o` vs `build/mc1 X -o b.o` → `cmp` idêntico (24+
  objetos); o pass demo altera `--dump-ast` de um teste específico conforme esperado; `make check`
  continua verde com `src/user.mc` **no default** (o demo é opt-in: ativar/desativar é trocar o
  include). `docs/surface.md` § Tier 2 com o passo a passo real.

## Orçamento
C: `&fn` + `callp` + divisão do gen + hooks ≈ 80 linhas (meta ≤ 2980). `.mc`: idem + módulos de
demonstração (não contam no orçamento).
