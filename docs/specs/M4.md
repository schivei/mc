# Spec M4 — tokenizador em `.mc` (cross-check gratuito)

Pré-requisito: M3. Objetivo: o primeiro programa de verdade na linguagem, e uma verificação cruzada
do lexer: `src/lex.mc` deve ser a **transliteração** de `stage0/lex.c`, função a função.

## Entrega (mc-dev)
- `src/lex.mc`: mesma tabela de tokens (mesma ordem de inserção, mesmos ids), mesmo casamento por
  maior prefixo, mesmos literais/escapes/comentários, mesma contagem de linhas. Sem `#rule`/prelúdio.
  Dados planos: tokens em array na arena com `#define TOK_ID 0`, `TOK_START 8`, ... e acessoras.
- `src/lexdump.mc`: `main` abre o arquivo dado em `argv[1]` (ler `ld64(argv + 8)`), tokeniza até
  EOF e imprime **exatamente** o formato de `mc0 --dump-tokens` (`LINHA ID TEXTO`).
- `scripts/check-lex.sh`: para cada `tests/*.mc` e `src/*.mc`, compara `mc0 --dump-tokens F` com
  `build/lexdump F` via `diff`; exit 1 em qualquer diferença.

## Aceite
`scripts/check-lex.sh` verde para todos os arquivos. Reportar linhas de `src/lex.mc`.
