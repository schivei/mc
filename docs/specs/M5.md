# Spec M5 — `#section`, `#opcode`, `emit()`, `reloc()`, `sys.mc` via `svc`

Pré-requisito: M4. É o marco que prova "emitir código de objfile e dizer para onde vai".

## Parser / diretivas
- `#section SEG SECT FLAGS[ ALIGN]`: cria (ou seleciona) a seção via `sec_new` e a torna a seção
  corrente para **funções** e **globais** declarados a seguir, até o próximo `#section`.
  `#section` sem argumentos volta ao default. Flags é constante dobrada (ex.: `0x80000400`).
- `#opcode nome(p1, p2, ...) EXPR`: registra um encoder em tabela linear `{name, params, tmpl}`.
  Chamada `nome(args)` em corpo de função: cada arg deve dobrar para constante (senão erro
  "argumento de #opcode nao constante"); o template é dobrado com os parâmetros substituídos e a
  palavra de 32 bits resultante vai para o buffer de instruções como `I_RAW`. Não é um símbolo.
- `emit(CONST)`: mesmo efeito, palavra crua. `reloc(TIPO, "simbolo")`: registra relocação para a
  **próxima** palavra emitida na função; `TIPO` ∈ `BRANCH26 PAGE21 PAGEOFF12 UNSIGNED` (constantes
  pré-definidas como `#define` internos). Símbolo desconhecido vira indefinido externo (`sym_ref`).
- Tabela de encoders e seção corrente são dados planos, ordem de inserção.

## Codegen
- `I_RAW` no buffer com o word; `--dump-asm` imprime `.word 0x........`.
- A relocação pendente de `reloc()` é anexada ao offset da próxima `I_RAW`/instrução.
- Garantir a promessa do plano: prólogo grava args no frame **sem** alterar `x0..x7`, e o valor de
  retorno de uma função que termina com `svc` é o `x0` deixado pela syscall (o epílogo não toca x0
  quando não há `return`).

## Biblioteca
- `lib/sys_svc.mc`: mesma interface de `lib/sys.mc` (`open/read/write/close/exit`) implementada com
  `#opcode mov16(rd, imm) 0xD2800000 | (imm << 5) | rd`, `#opcode svc(imm) 0xD4000001 | (imm << 5)`
  e números BSD `exit=1 read=3 write=4 open=5 close=6`.

## Testes
- `030-section.mc`: função em `__TEXT,__hot` e global em `__DATA,__tbl` → `otool -l` mostra as
  seções; programa roda → 42.
- `031-opcode.mc`: `#opcode` de `movz` e uso em função que retorna 42 sem `return`.
- `032-svc.mc`: `#include "../lib/sys_svc.mc"`; `write(1, "hi\n", 3)` via svc → stdout `hi\n`.
- `033-reloc.mc`: `reloc(BRANCH26, "_helper"); emit(0x94000000);` chamando função do próprio
  arquivo → 42; `otool -r` mostra a relocação.
