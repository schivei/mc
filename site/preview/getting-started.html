Getting started

Build the seed once with a C compiler, then never use a C compiler again. Fifteen minutes, four commands, and one program that compiles itself.

Build the seed #

stage0/ is 2,846 lines of C23 — a lexer, a Pratt parser, an AArch64 code generator and a Mach-O writer. It exists to compile exactly one program, src/mc.mc, and it is the only part of the repository a C compiler ever sees. 

git clone https://github.com/schivei/mc
cd mc
make stage0        # clang, once: build/mc0
make budget        # 2846/3000 lines - over budget is a build failure

make budget is not decoration. The seed has a hard ceiling of 3,000 lines, because a seed you cannot read in one sitting is a seed you have to trust instead of check.

Compile the compiler #

build/mc0 now compiles the real compiler. The result, build/mc1, understands strictly more than the seed does — #include <name>, #embed, taught backends, direct executables. 

make mc1           # build/mc0 compiles src/mc.mc  -> build/mc1
make bootstrap     # mc1 -> mc2.o, mc2 -> mc3.o, then cmp
make check         # everything: tests, cross-checks, bootstrap

The fixed point #

make bootstrap compiles the same source three times and compares the last two objects byte for byte. They are identical, which is the only useful definition of “self-hosting”: the compiler has stopped changing what it produces.

  1. mc0 compiles src/mc.mc into mc1.o.
  2. mc1 compiles the same source into mc2.o.
  3. mc2 compiles the same source into mc3.o.
  4. cmp mc2.o mc3.o reports no difference, and the SHA-256 is checked against tests/golden/mc2.sha256.

Your first program #

Put this in hello.mc:

#include <sys>

i64 main(i64 argc, uptr argv) {
    write(1, "hello from mc\n", 14);
    return 0;
}

build/mc1 --exe hello.mc -o hello
./hello
hello from mc

--exe writes the executable directly: segment layout, relocations, bind and rebase opcodes, and an ad-hoc code signature. No ld, no codesign. Without it you get a .o to link the ordinary way.

FlagWhat it writes
-o out.oa Mach-O object, the default
--exea signed Mach-O executable
--dump-tokensone line per token, with its file and line
--dump-astthe tree after every rule has expanded
--dump-asmthe instruction buffer before encoding
--dump-rulesevery #rule the file registered

Teach it something #

The core has no while. It has loop, if and break, which is enough to build one — and building one is a two-line directive, not a patch to the parser: 

// this is the whole of `while`, and it lives in lib/prelude.mc
#rule stmt: while ( expr $c ) block $b
    => loop { if (!$c) break; $b }

// and a hygienic one, where $$t is a fresh local per expansion
#rule stmt: swap ( ident $a , ident $b ) ;
    => { i64 $$t = $a; $a = $b; $b = $$t; }

Three tiers of teaching are available, each strictly larger than the last:

  • Tier 1 — directives: #token, #infix, #prefix, #rule, #section, #opcode.
  • Tier 2 — programs: pass() rewrites the AST, backend() replaces the code generator.
    • lib/backend_arm64.mc reimplements the whole encoder from the public API and produces byte-identical objects.
  • Tier 3 — handlers: syntax_stmt, syntax_expr, syntax_infix and type_alias add constructs the directives cannot express.
